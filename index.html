About This Test Page:

This HTML page tests the deep link functionality implemented in the DeepLinkManager.cs script.

When clicked, these links will trigger the Unity application with the specified parameters.

The DeepLinkManager will:

  • Capture the arguments passed via deep link
  • Display the received arguments on screen for 3 seconds
  • Attempt to load models based on the parameters
  • Create visual placeholders when model loading is attempted
  • Note: Full external model loading (FBX, glTF, GLB) requires additional libraries

For Full Model Loading:

To load actual 3D models from URLs, you would need to integrate a 3D model loading library such as:

  • glTFast - Fast glTF loading
  • UnityGLTF - glTF loader
  • Or implement custom format support

Once added, the DeepLinkManager will automatically handle model URLs.
